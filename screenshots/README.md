> **Instruction for Submitter**: Capture actual screenshots from your deployed project and save them in this folder using the filenames listed below before submitting your internship deliverable.

## Capture Recommendations
- **Resolution**: Capture at standard 1920x1080 or 1440x900 resolution.
- **Format**: PNG or high-quality JPEG.
- **Tools**: Windows Snipping Tool (`Win + Shift + S`), macOS Screenshot (`Cmd + Shift + 4`), or Chrome DevTools full-size screenshot (`Ctrl + Shift + P` → "Capture full size screenshot").
