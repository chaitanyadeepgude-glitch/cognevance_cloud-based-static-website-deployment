Company Overview

Cloud & DevOps System Architecture

Developer (Local Workstation) ↓ (HTML5 + CSS3 + Vanilla JS) Git Version Control (Local Repository) ↓ (git push origin main) GitHub Repository (cognevance_cloud_static_website) ↓ (Automated Deploy from /(root)) GitHub Pages Cloud Infrastructure (Fastly Global CDN) ↓ (Automated Let's Encrypt TLS / SSL) Public Live Website (https://<user>.github.io/cognevance_cloud_static_website/) ↓ (Continuous 5-Minute Synthetic Ping) UptimeRobot Availability Monitor (SLA Target: 99.9%)

Every component is decoupled: the developer pushes code to GitHub, GitHub Pages serves the static edge files across global Fastly nodes, and UptimeRobot verifies continuous availability.

GitHub Pages Deployment Checklist

  1. Create GitHub repository named cognevance_cloud_static_website (Public).
  2. Push all files from root to branch main.
  3. In GitHub, click Settings → Pages.
  4. Under Source: select Deploy from a branch.
  5. Under Branch: select main and folder /(root).
  6. Click Save and wait 60 seconds.
  7. Check Enforce HTTPS checkbox.
  8. Visit https://<your-username>.github.io/cognevance_cloud_static_website/.

Static Security & UptimeRobot Guide

Security Model: Defense-in-depth for serverless static hosting. By eliminating PHP, databases, and backend execution, 90% of web application vulnerabilities are mitigated natively.

  • Zero Secrets: No API tokens or passwords in client code.
  • Safe DOM: Strict textContent usage prevents DOM-XSS.
  • Tab-napping Defense: rel="noopener noreferrer" on outbound links.
  • Enforced HTTPS: Automatic Let's Encrypt 256-bit TLS encryption.
UptimeRobot Setup:
  1. Sign up for a free account at UptimeRobot.com.
  2. Click + Add New Monitor → Select HTTP(s).
  3. Enter name Cognevance Technologies and your published GitHub Pages URL.
  4. Set interval to 5 minutes and configure email notifications.
